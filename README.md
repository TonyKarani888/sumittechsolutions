sumittechsolutions™ one-page website

FILES
- index.html             Page content and section structure
- style.css              Layout, colors, typography, responsive behavior
- script.js              Hero carousel, mobile menu, Book a call contact panels
- logo-placeholder.svg   Temporary logo artwork; replace this file or change the src in index.html

RUN LOCALLY
Open index.html in a modern browser. Google Fonts and Font Awesome are loaded from their CDNs, so those icons and web fonts need an internet connection. The site otherwise uses plain HTML, CSS, and JavaScript.

BEFORE PUBLISHING
1. In index.html, replace src="logo-placeholder.svg" with the path to your logo image.
2. Replace each "YOUR PHONE NUMBER HERE" placeholder with your real business phone number.
3. Confirm the contact email and update any copy to match the exact service you offer.

The pricing note intentionally says that listing details and pricing are discussed directly; no fixed price is displayed.
